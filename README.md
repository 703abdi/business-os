# Business OS

A reusable operating system for a small business. It keeps everyday work in one place: a client CRM, scheduling and bookings, service and payment tracking, memberships/MRR, team operations, content planning, reviews, ads, metrics, forms, automations, and optional integrations.

Main pages include Today, Clients, Schedule, Revenue, Memberships, Sales, Content, Team, Metrics, Forms, Pages, Automations, Contacts, and Settings. The included records are clearly marked sample data and can be cleared from Settings when you are ready.
